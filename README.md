# Hinnerk – Entrümpelung Hamburg

Website für hinnerk-entruempelung.de (statisches HTML, GitHub Pages).

- Daten: `src/site.json` (Firma), `src/leistungen.json`, `src/stadtteile.json` (99 Hamburger Stadtteile, recherchiert mit Quellen)
- Bauen: `python3 src/build.py` (schreibt ins Hauptverzeichnis) oder `python3 src/build.py --out DIR` für eine Vorschau
- Branch `main` = live (erst nach Freigabe durch Talal). Arbeiten auf eigenem Branch.
- Schriften lokal (Zilla Slab, Archivo, SIL Open Font License), keine Cookies, Formular öffnet E-Mail.
